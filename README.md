# Sistema Web de Votaciones – Festival de la Leyenda Vallenata 2027

## Descripción
Este proyecto consiste en el desarrollo de un sistema web de votaciones para el Festival de la Leyenda Vallenata 2027. Permite gestionar categorías, participantes y procesos de votación mediante una aplicación web.

## Objetivo
Desarrollar una aplicación web que facilite la administración y organización de las votaciones del festival.

## Tecnologías utilizadas
- Python
- Django
- MySQL
- HTML y CSS
- Git y GitHub

## Funcionalidades
- Administración del sistema mediante Django Admin.
- Gestión de categorías y participantes.
- Organización de las votaciones.
- Almacenamiento de información en una base de datos MySQL.

## Instalación y ejecución

1. Clonar el repositorio:
   `git clone https://github.com/kcastaneda20-droid/sistema-votaciones-festival2027.git`

2. Entrar a la carpeta:
   `cd sistema-votaciones-festival2027`

3. Crear y activar un entorno virtual.

4. Instalar las dependencias:
   `pip install -r requirements.txt`

5. Configurar las variables de entorno y la conexión a MySQL.

6. Ejecutar las migraciones:
   `python manage.py migrate`

7. Iniciar el servidor:
   `python manage.py runserver`

8. Abrir en el navegador:
   `http://127.0.0.1:8000/`
